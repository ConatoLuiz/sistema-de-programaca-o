# Controle de Carteira de Projetos

Site estático (HTML único) com banco de dados Supabase.

- `index.html`: o sistema inteiro (a chave pública "anon" já está configurada nele)
- `supabase/setup.sql`: script do banco (rodar uma vez no SQL Editor do Supabase)
- `.nojekyll`: faz o GitHub Pages servir o arquivo como está

Nunca coloque a chave `service_role` neste repositório.
